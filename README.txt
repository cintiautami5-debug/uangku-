# UangKu — Manajemen Keuangan Pribadi Mahasiswa

Cara menjalankan:
1. Ekstrak folder/ZIP.
2. Buka `index.html` di browser.
3. Semua data transaksi tersimpan di LocalStorage browser.

File:
- index.html — struktur halaman
- style.css — tampilan dan responsive design
- script.js — logika aplikasi, CRUD, LocalStorage, filter, statistik, insight, export-ready structure

Catatan:
Website sudah berisi data contoh agar dashboard tidak kosong. Gunakan "Reset semua data" jika ingin mulai dari nol.
